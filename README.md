## Entry

Tell me the little app you've always wanted — the one that sorts your recipes or plans your weekends — and an AI agent will build a working version in minutes while you watch, and you only pay for the one you actually love.

Character count: 223 (limit 240, one sentence).

## Why this pitch

It speaks directly to a friend who has never coded, opening with the app they already dream about instead of abstract tech talk, and names concrete everyday examples — sorting recipes, planning weekends — so the idea feels like theirs, not a demo. The persuasion is a low-risk deal stated plainly: the agent builds a working version while they watch, and they only pay for the result they actually love, which gives them a concrete reason to say yes now rather than "someday". The language is plain throughout — no jargon, no slogans, no mention of models or code — so one read is enough. It stays truthful about what make.fun does: an AI agent builds the first app idea, and payment goes to the best result. And it sounds like a person talking to a friend, not a template: it starts with "Tell me", lingers on the little app they've always wanted, and ends on the warm, human note of paying only for something they love.
